# Spacer

An empty space for the Bar

## Features

- Takes up space without showing anything, to add gaps between other submodules or the edges of the bar
- Stays in place when neighbouring submodules are disabled

## Properties

Set on each Spacer where it's placed in the Bar.

| Name | Default  | Description                              |
|------|----------|------------------------------------------|
| size | (int) 16 | Width and height of the space in pixels. |
