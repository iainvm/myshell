# Bluetooth

The bluetooth settings show a searchable list, displaying all paired devices. It's built on the generic [SearchList](../../../../Components/SearchList/README.md) component.

## Features

- When the settings appear the search box is automatically focused
- When a device is connected a bluetooth icon is displayed next to it's name
- When a device is connected it's battery percentage is shown next to it's name
- When you click a device on the list it connects/disconnects the device
- When searching and the user hits "Enter" it will click the top result
